Safe explanations

A planned helper uses trace evidence and a small supported condition grammar; it never executes or guesses about unknown code.

How to try the current app

Until the planned one-command launcher is built, use two PowerShell terminals in the project root:

  1. npm run runner
  2. npm run dev

Open the Vite URL, normally http://localhost:5173/. Docker Desktop's Linux engine is required for actual code execution; the modeled simulator remains available without it.
